# Asset export steps run by play.sh and play.ps1, in order.
#
#   NAME  VERSION  LEGACY  PROGRAM  ARGUMENTS...
#
# Each step keeps a manifest in <cache>/exports/NAME.txt: its VERSION, then every
# file it produced. A step runs again when VERSION changes (re-exporting
# everything) or when a listed file is missing (exporting only what is missing,
# --missing). Bump VERSION when a program's output for that step changes.
#
# LEGACY marks caches made before manifests existed, so they are completed rather
# than rebuilt. Paths are relative to the cache:
#   -            none
#   exists:PATH  version 1 if PATH exists
#   stamp:PATH   the version written in the file PATH
#
# PROGRAM is a binary built from this workspace. In ARGUMENTS, {content} is the
# game's Content folder and {cache} the converted-asset cache. Fields are split
# on whitespace; no field may contain spaces.
#
# Every model step was bumped once on 2026-11-02: packed XNA Color COLOR0 vertex
# colours (VertexElementFormat.Color) are now exported.
